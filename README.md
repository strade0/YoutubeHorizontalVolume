# YouTube Viewport Volume Drag

Adjust YouTube video volume by dragging horizontally across the viewport.

---

## ✨ Features

- **Horizontal Drag Control**: Drag horizontally across the video to adjust volume (uses ~60% of player width for full 0% to 100% range).
- **Visualizer HUD**: A floating volume bar and waveform displayed directly above your mouse cursor.

---

## 🚀 Installation

1. Click the green **Code** button at the top of this repository and select **Download ZIP**.
2. Extract the downloaded ZIP file to a folder on your computer.
3. Open Google Chrome (or Edge / Brave / Opera) and go to `chrome://extensions/`.
4. Turn ON **Developer mode** using the toggle in the top-right corner.
5. Click **Load unpacked** in the top-left corner and select the extracted folder.
6. Open YouTube and drag your mouse across any video to adjust volume.
